# Finance Dashboard Backend

backend implementation for the finance dashboard assignment.

This version is built without external runtime dependencies. It uses Node.js core modules, a small in-house router, and a JSON file for persistence so the project stays easy to run and easy to explain.

## Quick Start

```bash
node --env-file-if-exists=.env src/server.js
```

## Available Scripts

- `npm start`
- `npm run dev`
- `npm test`
